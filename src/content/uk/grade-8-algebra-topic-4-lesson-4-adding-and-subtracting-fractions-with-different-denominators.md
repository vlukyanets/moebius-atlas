title: "[S] Додавання та віднімання дробів з різними знаменниками"
---

## Навіщо це потрібно

Дві труби наповнюють бак: одна за $x$ годин, інша за $x + 2$ годин.
Разом за годину вони роблять $\frac{1}{x} + \frac{1}{x + 2}$ роботи - і
щоб іти далі, це треба додати. Різні знаменники - звичайний випадок, а
спосіб той самий, що в 6 класі: знайти спільний знаменник, переписати,
додати. З многочленами спільний знаменник знаходять розкладанням на
множники, і саме цей крок вирішує, чи решта буде легкою, чи стане
кашею.

## Головна ідея

Спільний знаменник - многочлен, на який ділиться кожен знаменник.
Добуток знаменників завжди підходить, але часто він більший, ніж
треба; *найменший* спільний знаменник будують як НСК: розклади кожен
знаменник, візьми кожен різний множник у найвищому степені. Тоді кожен
дріб множать зверху і знизу на те, чого бракує його знаменнику, -
додатковий множник, - а чисельники об'єднують, як у випадку однакових
знаменників.

Труби: у $\frac{1}{x} + \frac{1}{x + 2}$ знаменники не мають нічого
спільного, тож НСЗ - $x(x + 2)$, а сума - $\frac{x + 2 + x}{x(x + 2)} =
\frac{2x + 2}{x(x + 2)}$.

## Правило

Щоб додати або відняти дроби з різними знаменниками:

1. **розклади** кожен знаменник на множники;
2. знайди **найменший спільний знаменник** - добуток усіх різних
   множників, кожен у найвищому степені, який він має в якомусь
   знаменнику;
3. знайди **додатковий множник** кожного дробу - НСЗ, поділений на його
   знаменник, - і помнож чисельник і знаменник на нього;
4. **об'єднай** чисельники над НСЗ, з дужками навколо чисельника, який
   віднімаєш;
5. **спрости** чисельник, розклади його, скороти, якщо можна.

Протилежні знаменники ($x - a$ і $a - x$) спершу роблять однаковими
зміною знака.

## Приклад крок за кроком

Спрости $\frac{3}{x - 2} - \frac{2}{x + 2}$, потім $\frac{x}{x^2 - 4} +
\frac{1}{x + 2}$, потім $\frac{1}{x} + \frac{1}{x + 2}$.

- **Перший.** Знаменники далі не розкладаються і не мають спільного:
  НСЗ $(x - 2)(x + 2)$. Додаткові множники $x + 2$ і $x - 2$. Чисельник:
  $3(x + 2) - 2(x - 2) = 3x + 6 - 2x + 4 = x + 10$. Результат $\frac{x +
  10}{(x - 2)(x + 2)}$.
- **Другий.** $x^2 - 4 = (x - 2)(x + 2)$ - це вже НСЗ. Другому дробу
  потрібен $x - 2$: $\frac{x + (x - 2)}{(x - 2)(x + 2)} = \frac{2x - 2}{(x -
  2)(x + 2)} = \frac{2(x - 1)}{(x - 2)(x + 2)}$.
- **Третій (труби).** $\frac{(x + 2) + x}{x(x + 2)} = \frac{2x + 2}{x(x + 2)}
  = \frac{2(x + 1)}{x(x + 2)}$.

З цілим виразом: $x - \frac{x^2}{x + 1} = \frac{x(x + 1) - x^2}{x + 1} =
\frac{x}{x + 1}$.

## Типова помилка

Помножити на додатковий множник лише знаменник. Переписати $\frac{3}{x -
2}$ як $\frac{3}{(x - 2)(x + 2)}$ - змінити його значення; чисельник теж
треба помножити: $\frac{3(x + 2)}{(x - 2)(x + 2)}$. Друга: брати добуток
знаменників, коли один - множник іншого: $\frac{x}{x^2 - 4} + \frac{1}{x +
2}$ не потребує $(x^2 - 4)(x + 2)$; НСЗ - сам $x^2 - 4$. Розклади, перш
ніж обирати.

## Висновок

Розклади знаменники, побудуй найменший спільний знаменник із кожного
різного множника в найвищому степені, помнож кожен дріб зверху і знизу
на те, чого йому бракує, об'єднай чисельники з дужками, спрости,
скороти. Уся робота - в кроці з НСЗ.

## Перевір себе

1. Знайди $\frac{1}{x} + \frac{1}{y}$.
2. Знайди $\frac{2}{a + 1} - \frac{1}{a - 1}$.
3. Знайди $\frac{x}{x - 3} - \frac{6}{x^2 - 9}$.
4. Знайди $\frac{1}{2x} + \frac{1}{3x^2}$.
5. Знайди $1 + \frac{a}{a - 1}$.
6. Хтось додає $\frac{1}{x} + \frac{1}{x + 1}$ і отримує $\frac{2}{x(x + 1)}$.
   Який правильний чисельник?

> [!spoiler] Відповіді
>
> 1. $\frac{x + y}{xy}$.
> 2. $\frac{2(a - 1) - (a + 1)}{(a + 1)(a - 1)} = \frac{a - 3}{a^2 - 1}$.
> 3. $\frac{x(x + 3) - 6}{(x - 3)(x + 3)} = \frac{x^2 + 3x - 6}{x^2 - 9}$.
> 4. НСЗ $6x^2$: $\frac{3x + 2}{6x^2}$.
> 5. $\frac{a - 1 + a}{a - 1} = \frac{2a - 1}{a - 1}$.
> 6. $(x + 1) + x = 2x + 1$; сума $\frac{2x + 1}{x(x + 1)}$.
