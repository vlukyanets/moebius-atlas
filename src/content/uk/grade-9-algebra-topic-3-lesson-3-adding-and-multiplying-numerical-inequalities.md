---
title: "[S] Додавання і множення числових нерівностей"
---

## Навіщо це потрібно

Кімната від $3$ до $4$ метрів завдовжки і від $2$ до $3$ завширшки - що
можна сказати про її площу чи периметр? Дві нерівності треба з'єднати
в одну. Додавання нерівностей і їх множення - те, як похибки
вимірювань, оцінки й межі проносяться через обчислення, і правила для
цього короткі, якщо помітити, чого робити *не можна*.

## Головна ідея

Дві нерівності одного напряму можна додати: якщо $a > b$ і $c > d$, то
$a + c > b + d$. Чому: $a + c - (b + d) = (a - b) + (c - d)$, сума двох
додатних. Для множення працює те саме, але лише для *додатних* чисел:
$ac - bd = ac - bc + bc - bd = c(a - b) + b(c - d)$, додатне, коли все
додатне. Від'ємні все псують: $-1 > -2$ і $-1 > -3$, але $(-1)(-1) = 1$ не
більше за $(-2)(-3) = 6$.

Чого не можна робити - віднімати чи ділити нерівності почленно:
напрями не поєднуються.

## Правило

**Теорема 1.** Якщо $a > b$ і $c > d$, то $a + c > b + d$. Нерівності одного
напряму можна почленно додавати.

**Теорема 2.** Якщо $a > b > 0$ і $c > d > 0$, то $ac > bd$. Нерівності одного
напряму між **додатними** числами можна почленно множити.

**Наслідок.** Якщо $a > b > 0$, то $a^n > b^n$ для кожного натурального $n$.

Не можна: почленно віднімати чи ділити нерівності; додавати
нерівності протилежних напрямів (спершу переверни одну, помноживши
на $-1$).

## Приклад крок за кроком

Довжина кімнати задовольняє $3 < a < 4$, ширина $2 < b < 3$ (метри).
Оціни периметр і площу. Потім: дано $1 < x < 2$ і $3 < y < 5$, оціни $x - y$
і $\frac{x}{y}$.

- **Периметр $2(a + b)$.** Додай: $5 < a + b < 7$; подвой: $10 < 2(a + b) <
  14$.
- **Площа $ab$.** Усе додатне, помнож: $6 < ab < 12$.
- **$x - y$.** Почленно віднімати не можна. Натомість запиши $x - y = x +
  (-y)$: з $3 < y < 5$ маємо $-5 < -y < -3$; додай до $1 < x < 2$: $-4 < x - y
  < -1$.
- **$\frac{x}{y}$.** Запиши як $x \cdot \frac{1}{y}$: $\frac{1}{5} < \frac{1}{y} <
  \frac{1}{3}$, додатні, помнож: $\frac{1}{5} < \frac{x}{y} < \frac{2}{3}$.

Прийом в обох: перетвори віднімання на додавання від'ємного, ділення
- на множення на обернене, і спершу правильно переверни *внутрішню*
нерівність.

## Типова помилка

Віднімати почленно: з $1 < x < 2$ і $3 < y < 5$ отримати $1 - 3 < x - y < 2 -
5$, тобто $-2 < x - y < -3$, що навіть не проміжок. Межі для $x - y$ - від
*найменшого* $x$ мінус *найбільший* $y$ до найбільшого $x$ мінус
найменший $y$: від $-4$ до $-1$. Додавання $-y$ робить це автоматично.
Так само множення, коли якісь числа можуть бути від'ємними: $-2 < a < 1$
і $-3 < b < 2$ не дають $6 < ab < 2$.

## Висновок

Нерівності одного напряму додаються; нерівності одного напряму між
додатними числами множаться. Щоб відняти, додай від'ємне; щоб
поділити, помнож на обернене, перевертаючи при цьому внутрішню
нерівність. Ніколи не віднімай і не діли почленно.

## Перевір себе

1. Дано $2 < a < 5$ і $1 < b < 3$. Оціни $a + b$.
2. Ті самі дані: оціни $ab$.
3. Ті самі дані: оціни $a - b$.
4. Ті самі дані: оціни $\frac{a}{b}$.
5. Дано $0{,}5 < x < 0{,}6$. Оціни $x^2$.
6. Хтось оцінює $a - b$ з $2 < a < 5$, $1 < b < 3$ як $1 < a - b < 2$. Що пішло
   не так?

> [!spoiler] Відповіді
>
> 1. $3 < a + b < 8$.
> 2. $2 < ab < 15$.
> 3. $-1 < a - b < 4$.
> 4. $\frac{2}{3} < \frac{a}{b} < 5$.
> 5. $0{,}25 < x^2 < 0{,}36$.
> 6. Відняли почленно; правильно $-1 < a - b < 4$.
