title: "[S] Числові послідовності"
---

## Навіщо це потрібно

Щомісячні платежі, висоти м'яча, що скаче, кількість клітин після
кожного поділу, цифри $\pi$ - послідовність - це список чисел по
порядку, і половина прикладної математики про те, як передбачити
наступне. Цей розділ вивчає два найпростіші види, арифметичну і
геометричну, а тут - мова: що таке послідовність, як називати її
члени і два способи її задати: формулою $n$-го члена або правилом
отримання кожного з попереднього.

## Головна ідея

Послідовність - функція, чиї входи $1, 2, 3, \dots$ - *позиція* - а
виходи - члени. Замість $f(1), f(2)$ пишеш $a_1, a_2$, і $a_n$ - член на
позиції $n$. Два способи сказати, що це. Формула для $a_n$ через $n$
дозволяє стрибнути одразу до будь-якого члена: $a_n = n^2$ дає $a_{10} =
100$ одразу. *Рекурентне* правило каже, як кожен член робиться з
попередніх: "почни з $3$, щоразу додавай $5$" - щоб дістатись $a_{10}$,
проходиш через $a_2, \dots, a_9$, але правило часто якраз те, що
ситуація насправді каже.

## Правило

**Числова послідовність** - функція, визначена на множині натуральних
чисел (або на перших $n$ з них). Її значення $a_1, a_2, a_3, \dots$ -
**члени**; $a_n$ - **$n$-й член** або **загальний член**; $n$ - його
номер. Послідовність записують $(a_n)$.

Послідовність **скінченна**, якщо має скінченно багато членів, інакше
**нескінченна**.

Способи задати послідовність:

- **формулою $n$-го члена**, $a_n = f(n)$, напр. $a_n = 2n - 1$;
- **рекурентно**: перший член (члени) і правило, що виражає $a_{n + 1}$
  через попередні, напр. $a_1 = 3$, $a_{n + 1} = a_n + 5$;
- переліком або описом ("прості числа в порядку зростання").

## Приклад крок за кроком

Випиши перші п'ять членів $a_n = \frac{n}{n + 1}$; $b_1 = 2$, $b_{n + 1} = 3b_n -
1$. Потім знайди формулу для послідовності $5, 8, 11, 14, \dots$ і
перевір, чи $302$ - її член.

- **$a_n = \frac{n}{n + 1}$:** $\frac{1}{2}, \frac{2}{3}, \frac{3}{4}, \frac{4}{5},
  \frac{5}{6}$. Будь-який член одразу: $a_{99} = \frac{99}{100}$.
- **Рекурентно:** $b_1 = 2$, $b_2 = 5$, $b_3 = 14$, $b_4 = 41$, $b_5 = 122$. Щоб
  отримати $b_5$, довелось обчислити чотири перед ним.
- **Формула для $5, 8, 11, 14$.** Кожен на $3$ більший за попередній, а
  перший $5 = 3 \cdot 1 + 2$: $a_n = 3n + 2$. Перевір $a_4 = 14$.
- **Чи $302$ - член?** $3n + 2 = 302$, $n = 100$ - натуральне, тож так, $302
  = a_{100}$. (Для $301$: $n = \frac{299}{3}$, не ціле - не член.)

Номер завжди натуральне число; $a_0$ чи $a_{2{,}5}$ нічого не означають.

## Типова помилка

Плутати член з його номером: "число $14$ - $4$-й член" - це $a_4 = 14$, а
$a_{14}$ - щось інше ($44$). І вважати, що послідовність, задана
кількома першими членами, має лише одне продовження: $1, 2, 4, \dots$
може бути $2^{n - 1}$, а може бути $1, 2, 4, 7, 11$ (різниці ростуть на
$1$). Кілька членів *підказують* правило; формула його *задає*.

## Висновок

Послідовність - функція від позиції $n = 1, 2, 3, \dots$; $a_n$ - член на
позиції $n$. Задавай формулою для $a_n$, що стрибає до будь-якого
члена, або рекурентно, що будує кожен з попереднього. Щоб перевірити
належність, розв'яжи $a_n = $ значення відносно натурального $n$.

## Перевір себе

1. Випиши перші чотири члени $a_n = n^2 - 1$.
2. Випиши перші чотири члени $c_1 = 1$, $c_{n + 1} = 2c_n + 1$.
3. Знайди формулу $a_n$ для послідовності $2, 4, 6, 8, \dots$; для $1, 4,
   9, 16, \dots$.
4. Чи $50$ - член $a_n = 4n + 2$? А $51$?
5. Знайди $a_{20}$ для $a_n = \frac{(-1)^n}{n}$.
6. Хтось каже, що послідовність $2, 4, 8, \dots$ мусить продовжуватись
   числом $16$. Наведи інше правило, що підходить до перших трьох.

> [!spoiler] Відповіді
>
> 1. $0, 3, 8, 15$.
> 2. $1, 3, 7, 15$.
> 3. $a_n = 2n$; $a_n = n^2$.
> 4. $4n + 2 = 50$, $n = 12$: так. $4n + 2 = 51$: $n$ не ціле, ні.
> 5. $\frac{1}{20}$.
> 6. Наприклад $a_n = n^2 - n + 2$: $2, 4, 8, 14, \dots$
