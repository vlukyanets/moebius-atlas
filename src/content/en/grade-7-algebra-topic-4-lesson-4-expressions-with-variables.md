## Why It Matters

Algebra is the art of calculating with numbers you don't know yet.
$2a + 3b$, $x^2 - 5x$, $\frac{m + n}{2}$ - each is a recipe waiting for
numbers, and each behaves like a number in its own right: it can be
added to, multiplied, compared. Before you can transform such
expressions - the whole business of the next twenty topics - you need
to know what they are, what values they can take, and which ones are
built only from the four operations you can always carry out.

## The Big Idea

An expression with variables is a machine: put numbers in for the
letters, turn the handle, get a number out. $2a + 3b$ with $a = 1$, $b =
4$ gives $14$. Change the inputs and the output changes. The set of
inputs the machine accepts is its domain - and some machines refuse
certain inputs: $\frac{10}{x - 3}$ jams at $x = 3$, because that would be
a division by zero.

Expressions built with only addition, subtraction, multiplication and
division by *numbers* - never by a variable - accept every input. They
are the integer expressions, and they're the ones this year is about.
An expression that divides by something with a variable in it is
fractional, and it comes with a warning label.

## The Rule

An **expression with variables** is a record made of numbers, letters,
operation signs and brackets, such as $2a + 3b$ or $\frac{x - 1}{x + 1}$.
Its **value** for given values of the variables is the number obtained
by substituting and calculating.

The **domain** (set of admissible values) of an expression is the set of
values of its variables for which the expression makes sense - that
is, no division by zero occurs.

An expression built from numbers and variables using addition,
subtraction, multiplication and division by a **non-zero number** is
an **integer rational expression** - an **integer expression** for
short. Its domain is all numbers. Examples: $3x^2 - 2x + 1$,
$\frac{a + b}{5}$, $(m - n)(m + n)$.

An expression that involves division by an expression containing a
variable is a **fractional expression**: $\frac{10}{x - 3}$,
$\frac{a}{b} + 1$.

## Worked Example

Find the value of $3x^2 - 2xy + 5$ for $x = -2$, $y = 3$; then find the
domain of $\frac{x + 4}{x - 3}$ and of $\frac{x + 4}{3}$, and say which
is an integer expression.

- **Value.** Substitute: $3 \cdot (-2)^2 - 2 \cdot (-2) \cdot 3 + 5 = 3 \cdot
  4 + 12 + 5 = 29$. Note $(-2)^2 = 4$ - the square of a negative number is
  positive.
- **$\frac{x + 4}{x - 3}$.** The denominator $x - 3$ is $0$ when $x = 3$.
  Domain: all numbers except $3$. It divides by a variable expression -
  fractional.
- **$\frac{x + 4}{3}$.** Division by the number $3$ - always allowed.
  Domain: all numbers. An integer expression.

Which of these are integer expressions? $2a(a - 1)$ - yes; $\frac{a}{2} -
\frac{2}{a}$ - no, the second term divides by $a$; $0.5b^3 - 7$ - yes.

## Common Mistake

Calling $\frac{x + 4}{3}$ fractional "because it's a fraction." What
matters isn't the fraction bar but *what's below it*: a number is
fine, a variable expression isn't. $\frac{x + 4}{3}$ is $\frac{1}{3}x +
\frac{4}{3}$, an integer expression with fractional coefficients. And
the other way round: $\frac{2}{a}$ has no visible fraction bar problem,
but $a = 0$ breaks it.

## The Takeaway

An expression with variables turns input numbers into an output
number; its domain is every input that avoids dividing by zero.
Integer expressions divide only by numbers and accept every input;
fractional ones divide by a variable expression and must exclude the
values that make it zero.

## Check Yourself

1. Find the value of $a^2 - 3ab$ for $a = -1$, $b = 2$.
2. Find the value of $\frac{2x - 1}{x + 2}$ for $x = 3$. For which $x$ is
   it undefined?
3. Which are integer expressions: $\frac{m}{7}$, $\frac{7}{m}$, $m^2 -
   \frac{m}{3}$, $\frac{1}{m - 1}$?
4. Find the domain of $\frac{5}{x(x - 2)}$.
5. Write an integer expression for "the sum of the squares of $a$ and
   $b$, divided by $2$."
6. Someone says $\frac{x}{4}$ is a fractional expression. Correct them.

> [!spoiler] Answers
>
> 1. $1 + 6 = 7$.
> 2. $1$; undefined at $x = -2$.
> 3. $\frac{m}{7}$ and $m^2 - \frac{m}{3}$.
> 4. All numbers except $0$ and $2$.
> 5. $\frac{a^2 + b^2}{2}$.
> 6. It divides by the number $4$, so it's an integer expression, equal to
>    $0.25x$.
