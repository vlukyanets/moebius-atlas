If a function takes each value at exactly one point - which is guaranteed by monotonicity - the correspondence can be read backwards, and $y = f(x)$ becomes $x = f^{-1}(y)$. The graphs of $f$ and $f^{-1}$ are symmetric about the line $y = x$.
