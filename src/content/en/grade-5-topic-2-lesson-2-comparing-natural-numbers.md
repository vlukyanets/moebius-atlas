## Why It Matters

Which city has more people, which phone has more storage, which team is
winning by more goals - questions like these are all really asking the same
thing: which number is bigger? Once you can compare numbers with
confidence, every one of those questions gets easy.

## The Big Idea

Picture two numbers as two towers built from blocks, one block for every
digit. To see which tower is taller, first count the blocks - the tower with
more blocks is always taller, no matter what's written on them. Only when
both towers have exactly the same number of blocks do you need to climb down
from the top, block by block, until you find the first one that doesn't
match - and that block settles it.

## The Rule

Comparing two numbers takes two steps. **First, count the digits: the number
with more digits is always bigger**, no matter what those digits are. **If
both numbers have the same number of digits, compare them digit by digit,
starting from the left**, until you find one that differs - that digit
decides which number is bigger. The result is written with $<$ (less than),
$>$ (greater than), or $=$ (equal).

## Worked Example

Which is bigger, $4278$ or $4269$?

- **Count the digits.** Both numbers have four digits - same, so that
  doesn't help. Look closer.
- **Compare from the left.** The thousands digits are both $4$ - same, move
  on.
- The hundreds digits are both $2$ - same again, move on.
- The tens digits differ: $7$ versus $6$. Since $7 > 6$, that's it, you
  already have the answer - you don't even need to check the ones digit,
  because the digit in the more important place already decided it.

So $4278 > 4269$.

## Common Mistake

Some people jump straight into comparing digit by digit, and forget to count
the digits first. Compare $87$ and $138$ that way - $8$ against $1$ - and
you might guess $87$ is bigger, since $8 > 1$. That's wrong: $138$ has three
digits, $87$ has only two, and a number with more digits is always bigger, no
matter what those digits are. Count the digits first. Only compare digit by
digit once the digit counts match.

## The Takeaway

When you compare two natural numbers, the digit count decides everything
first - only when the counts match do the digits themselves, read left to
right, decide.
