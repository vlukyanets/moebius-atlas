## Why It Matters

A formula tells you the value of a function at one point at a time. A
graph tells you about all of them at once: where the function is
zero, where it's biggest, where it climbs and where it falls. That's
why every dashboard, every stock ticker and every science paper shows
a graph rather than a formula. Being able to draw one from a rule, and
read a rule's behaviour off one, is a skill you'll use in every
subject that has numbers in it.

## The Big Idea

Take every input $x$ in the domain, compute the output $y$, and mark
the point $(x; y)$ on the coordinate plane. Do that for all inputs and
the points form a shape - the graph. It's the function drawn out: the
$x$-axis holds the inputs, the height of the graph above (or below)
each input is its output.

Because a function has exactly one output per input, the graph has a
special property: any vertical line crosses it at most once. A shape
that a vertical line cuts twice isn't the graph of a function - it
would be giving one input two outputs.

## The Rule

The **graph of a function** $y = f(x)$ is the set of all points $(x; y)$
of the coordinate plane whose abscissa $x$ is in the domain and whose
ordinate $y$ is the value $f(x)$.

**To plot from a formula:** make a table of values, plot the points,
join them (when the function is defined on a whole interval).

**To read a graph:**

- the value at $x = a$: go up from $a$ to the graph, across to the
  $y$-axis;
- the domain: the set of $x$ under (or over) which the graph has
  points; the range: the set of $y$ the graph reaches;
- zeros of the function: where the graph meets the $x$-axis;
- $f(x) > 0$ where the graph is above the axis, $f(x) < 0$ where it's
  below.

**Vertical line test:** a set of points is the graph of a function only
if no vertical line meets it more than once.

## Worked Example

Plot $y = x^2 - 4$ for $-3 \leq x \leq 3$, and read from the graph the
zeros, the range, and where $y < 0$.

- **Table:** $x = -3, -2, -1, 0, 1, 2, 3$ gives $y = 5, 0, -3, -4, -3, 0, 5$.
- **Plot and join:** a U-shaped curve with its bottom at $(0; -4)$.
- **Zeros:** the curve meets the $x$-axis at $x = -2$ and $x = 2$.
- **Range** (on this interval): from the lowest point $-4$ up to $5$.
- **$y < 0$:** the curve is below the axis between the zeros, for $-2 < x
  < 2$.

Now a graph handed to you: it passes through $(1; 3)$ and $(4; 3)$ and
nothing lies above it at $x = 2$ except the point $(2; 5)$. So $f(1) = 3$,
$f(4) = 3$, $f(2) = 5$ - all readable without any formula.

## Common Mistake

Reading the wrong coordinate. "Find $f(2)$" means: go to $2$ on the
*horizontal* axis, up to the graph, and read the *height*. Some people
go to $2$ on the vertical axis instead - that answers "for which $x$ is
$f(x) = 2$," a different question with possibly several answers.
Input is horizontal, output is vertical, always.

## The Takeaway

The graph is every point $(x; f(x))$ drawn on the plane. Inputs run
along the $x$-axis, outputs are heights; zeros are where it crosses
the axis; and a vertical line never cuts a function's graph twice.

## Check Yourself

1. Does the point $(2; 3)$ lie on the graph of $y = x^2 - 1$? Does
   $(-2; 3)$?
2. Plot $y = 2x - 1$ for $x$ from $-1$ to $3$ and read $f(1.5)$.
3. A graph crosses the $x$-axis at $-1$ and $4$. What are the zeros?
4. From the graph of $y = x^2 - 4$, for which $x$ is $y > 0$ (within $-3
   \leq x \leq 3$)?
5. A circle is drawn on the coordinate plane. Is it the graph of a
   function? Why not?
6. Someone finds $f(2)$ on a graph by going to $2$ on the $y$-axis and
   reading across. What did they find instead?

> [!spoiler] Answers
>
> 1. Yes ($4 - 1 = 3$); yes ($4 - 1 = 3$).
> 2. $f(1.5) = 2$.
> 3. $-1$ and $4$.
> 4. $-3 \leq x < -2$ and $2 < x \leq 3$.
> 5. No - a vertical line through it meets it twice.
> 6. The $x$ values where $f(x) = 2$, not the value of $f$ at $2$.
