A rule that assigns exactly one value $y$ to each admissible value $x$. The set of admissible $x$ is the domain, the set of obtained $y$ is the range, and the set of points $(x; y)$ drawn in the plane is the graph.

A vertical line meets a graph at most once - that is the picture of "exactly one value".
